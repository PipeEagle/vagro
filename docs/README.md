# Documentación - AgroGestión

Este directorio reúne diagramas, decisiones arquitectónicas y documentos de proceso. Los documentos de proceso pueden describir requisitos o propuestas; para conocer el comportamiento implementado, contrasta con el código y con los manuales del proyecto.

Los diagramas `.drawio` se pueden abrir con [draw.io / diagrams.net](https://app.diagrams.net/) seleccionando **Dispositivo** y luego el archivo local.

## Archivos

| Archivo | Descripción |
|---|---|
| `arquitectura.drawio` | Vista de arquitectura propuesta del monolito modular |
| `entidad-relacion.drawio` | Modelo de datos de referencia; comparar con `backend/MODELO_DATOS.md` antes de usarlo como esquema vigente |
| `flujo-api.drawio` | Flujo de referencia para API y autenticación |
| `ADR-001.md` | Decisión arquitectónica del monolito modular |
| `DOR_DOD.md`, `JIRA_GESTION.md`, `RACI.md` | Criterios y documentos de gestión del proyecto |
| `control-documental/` | Requisitos, contexto y material de proceso |
| `Guion_Video_Proyecto_Final_AgroGestion.md` | Guion de grabación basado en la implementación actual |

Para ejecución y estado actual, consulta `../arranque.txt`, `../README.md` y `../backend/README.md`.

## Cómo abrir

1. Ve a https://app.diagrams.net/
2. Haz clic en **Dispositivo** y selecciona el archivo `.drawio` deseado.
3. O arrastra el archivo directamente al lienzo de draw.io.
