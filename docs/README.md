# Docs - AgroGestión

Este directorio contiene los diseños del sistema en formato draw.io (`.drawio`).
Abrí los archivos con [draw.io / diagrams.net](https://app.diagrams.net/) seleccionando "Dispositivo" → abrir archivo local.

## Archivos

| Archivo | Descripción |
|---|---|
| `arquitectura.drawio` | Arquitectura de software: Monolito Modular por Capas (5 capas + Shared) |
| `entidad-relacion.drawio` | Diagrama ER de la base de datos MySQL (`usuarios`, `cultivos`, `lotes`, `labores`) |
| `flujo-api.drawio` | Flujo de los endpoints públicos y de autenticación del administrador |

## Cómo abrir

1. Ve a https://app.diagrams.net/
2. Haz clic en **Dispositivo** y selecciona el archivo `.drawio` deseado.
3. O arrastra el archivo directamente al lienzo de draw.io.
