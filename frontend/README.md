# Frontend

La interfaz usa plantillas Jinja servidas por Flask y estilos basados en Bootstrap.

- `templates/base.html`: layout comun.
- `templates/worker/`: flujos de trabajador de campo.
- `templates/admin/`: vistas administrativas.
- `static/`: estilos y JavaScript del cliente.

Las acciones de los formularios y el escaneo por camara se conectaran cuando se definan las rutas y los flujos de autenticacion del backend.
